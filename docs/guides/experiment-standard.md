# 实验可复现规范

每个实验都必须让读者能回答：在哪个环境执行、需要什么依赖、如何运行、看到什么算成功、如何退出与清理。

## 必填结构

1. **目标与风险**：本实验验证的机制，以及是否需要 root、虚拟机或专用设备。
2. **环境**：操作系统/架构、内核或源码版本、编译器/工具版本、权限和依赖。
3. **准备**：工作目录、输入文件、镜像或配置；所有命令从仓库根目录或明确目录执行。
4. **运行**：完整命令，不省略关键参数；需要多个终端时标注终端 A/B。
5. **预期结果**：给出关键输出片段或可观察状态，并说明哪些内容会随环境变化。
6. **失败排查**：列出最可能的依赖、权限、版本、符号和配置问题。
7. **清理**：明确如何停止进程、卸载模块、删除构建产物、恢复配置和释放端口。
8. **边界**：说明示例不证明什么；性能测试必须记录 workload、基线、硬件和重复次数。

## 安全要求

- 内核模块、驱动、eBPF、kdump、网络配置和权限实验优先在可丢弃 VM 中运行。
- QEMU GDB stub 只绑定回环接口，不暴露到公网。
- 不要将未经审计的教学代码部署到生产环境。
- 对 destructive command、root 权限和系统重启要求作醒目标注。
