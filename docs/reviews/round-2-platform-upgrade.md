## 验证边界

- GitHub Actions 的结果以本次提交对应的 workflow run 为准；提交时可能仍处于排队或运行中。
- Playwright 测试覆盖的是浏览器冒烟与首页多视口，不等于完整视觉回归、屏幕阅读器验收或每个章节的所有交互验收。
- 尚未在此轮执行四组实验的真实内核/硬件运行验证。
- 外部官方链接尚未进行全量在线可用性审计。
- 28 章的逐段 API/代码事实审计仍需分批进行；本轮建立了可持续执行的检查入口和记录规范。
