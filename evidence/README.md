# 章节证据清单

第 01–14 章各自的 JSON 文件将关键技术论断映射到官方规范、Linux 内核文档、上游源码或语言规范。每条记录包含 claim、kind、source_url、locator、status 与 notes。

- `verified`：来源直接支持该论断。
- `derived`：基于多个来源或实现细节作出的归纳，已标出边界。
- `illustrative`：用于解释机制的示意内容，不是测量结果。
- `unverified`：仍需进一步核实，不应当作已证实事实。

证据清单覆盖章节中的关键技术主张，不是对文章每句话、所有发行版或所有内核版本的形式化证明。请结合 source locator 和目标环境核对版本差异。
