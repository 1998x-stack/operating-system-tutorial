# 章节证据清单

第 01–28 章各自的 JSON 文件将主要技术论断映射到官方规范、内核文档或上游项目资料。字段中的 `status` 说明证据状态：`verified` 为来源直接支持，`derived` 为基于来源的归纳，`illustrative` 为仅用于解释的示意内容，`unverified` 表示仍需核实。

证据文件不是对整章每一句话的形式化证明；它用于追踪关键事实、接口和版本边界。


第二轮平台升级增加了静态校验：检查 01–28 章证据文件是否存在、JSON 字段与来源 URL 是否满足基本结构要求。此项结构检查不等同于人工核对每个来源是否仍然有效或完全支持对应论断。
